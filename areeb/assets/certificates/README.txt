PLACE YOUR CERTIFICATE FILES IN THIS FOLDER
============================================
Use these exact file names (extension can be .jpg, .jpeg, .png, .webp or .pdf):

  app-development-certificate-01        -> App Development Certificate 01
  app-development-certificate-02        -> App Development Certificate 02
  python-development-certificate        -> Python Development Certificate
  huawei-hcia-datacom-v1-certificate    -> HCIA-Datacom V1.0 Course (Huawei)
  comstech-flutter-internship-certificate -> Flutter Developer Internship Certificate (Comstech Solutions, Hyderabad, 2 Months)

Example: assets/certificates/python-development-certificate.jpg

The "View Certificate" button on the website finds the file automatically.
Until a file is added, visitors see "Certificate preview will be available soon."
