Comstech Testing Service (CTS) — Case Study

Online Examination & Assessment Management SystemMobile & Web Platform

Overview

Comstech Testing Service (CTS) is an online examination management system designed to digitize and simplify examination operations for educational institutions and testing organizations.

The platform gives administrators, students and examination teams one structured environment to manage assessments, conduct online exams, monitor student activity and manage results.

Main Objectives

  • Digitize traditional examination processes
  • Simplify examination administration
  • Centralize student and test management
  • Improve examination monitoring
  • Provide organized result management
  • Reduce manual administrative work

Problem

Traditional examinations depend on manual administration: papers and candidate lists are prepared by hand, supervision is limited, and results take time to compile. This makes it hard to keep tests fair, organized and easy to manage at scale.

Solution

CTS moves the whole examination cycle into one platform. Super admins create exams and assign them to specific students, students take timed tests on their own devices under live supervision, and results are processed automatically against the configured passing rule.

Key Features

Student Management

  • Student IDs created and managed by authorized administrators
  • Role-based access for super admins and students
  • Per-student test assignment and visibility
  • Students see only the exams assigned to them

Examination Management

  • Exam Studio: duration, total marks, total questions and a 50% passing rule
  • Question import from PDF papers and bulk Excel files
  • Assignment-based exam availability
  • Test approval workflow

Live Examination Monitoring (key feature)

  • Super admin can watch any student live through their camera during the test
  • Warning messages sent to the student from the live screen (e.g. "Please look at your screen")
  • Students see a small live camera tile, so they know monitoring is active
  • Violations (tab switch, app minimized, face not visible) logged in real time
  • Proctoring controls: face presence, microphone check, tab-switch detection and a violation limit
  • When the violation limit is crossed, the attempt is auto-failed and locked
  • Timed exam with a question navigator

Result Management

  • Automatic result processing; 50% or above is declared a pass
  • Instant result with a performance summary for students
  • Result reports and a merit leaderboard

Admin Dashboard

  • Dashboard with platform users, admins, pending approvals and access requests
  • Audit logs, branding settings and admin accounts
  • Centralized student and examination records

Security & Access

  • Role-based secure login
  • Controlled student access to assigned tests only
  • Administrative permissions and approval workflow
  • Real-time activity monitoring during exams

Technology

FlutterDartRiverpodLaravelPHPREST APIsJSONRole-Based AuthLive Monitoring

My Contribution

  • Flutter application development for super admin and student roles
  • Backend API integration with the Laravel backend
  • Examination interfaces: splash, login, assigned exams, rules and consent, timed MCQ exam and results
  • Fully responsive UI across mobile, tablet and web
  • Live monitoring screens, including the camera preview fix (sizing and rotation) for the proctoring screen
  • Assignment-based test access in both backend and app
  • Environment-based API configuration for clean deployment
  • Splash screen, app icon and branding

Project Impact

CTS helps organize online examinations in one place: administrators spend less time on manual work, student and exam records are centralized, and supervised digital assessments become practical through live camera monitoring, violation logging and automatic result processing.
