ChatMind AI — Case Study

Overview

ChatMind AI is a mobile chat application built with Flutter, designed for interacting with AI assistants through a clean, modern interface.

Problem

Most AI chat clients on mobile are cluttered or lock users into a single model provider, with no control over which API key or model is used.

Solution

A lightweight Flutter client that connects to the OpenRouter API, letting users choose between multiple AI models while keeping their API key stored securely on-device.

Key Features

  • AI conversation via OpenRouter API
  • Google Sign-In and email/password authentication
  • Multiple AI model selection
  • Persistent conversation history
  • Dark / light theme

Overview

Problem
